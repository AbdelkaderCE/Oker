## Reporting a Vulnerability

If you discover a security vulnerability in Oker, please report it responsibly.

- Email: kader2aek2@gmail.com 
- Do not publicly disclose the issue until it has been addressed.
- You can expect a response within 7 days.

Thank you for helping make Oker safer for everyone.
