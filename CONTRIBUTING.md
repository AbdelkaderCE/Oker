  # Contributing to Oker

  Thank you for your interest in contributing to **Oker**, a programming language written in C++.

  ## Getting Started
  - Fork the repository
  - Create a new branch (`git checkout -b feature-name`)
  - Make your changes
  - Commit and push your branch
  - Open a Pull Request

  ## Reporting Issues
  - Use the Issues tab
  - Describe the problem clearly
  - Include system and compiler information if possible

  ## Code Style
  - Use modern C++ (C++17 or later)
  - Keep code readable and documented

  ## License
  By contributing, you agree that your work will be licensed under the same license as the Oker project.
